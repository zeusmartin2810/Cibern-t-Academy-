# CyberNet Academy

Plataforma educativa de redes y ciberseguridad con calculadora IPv4/CIDR.

## Uso
Abre `index.html` en el navegador o publica el repositorio con GitHub Pages (Settings → Pages → Deploy from a branch → main → /root).

Incluye cálculo de máscara, red, broadcast, primera/última IP, direcciones totales, hosts utilizables y salto. Los prefijos /31 y /32 tienen tratamiento especial.
